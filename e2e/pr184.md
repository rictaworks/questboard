# PR #184: 管理者ユーザー管理画面のHTTP 500エラーを修正（flashサポート復元）

- PR: https://github.com/rictaworks/questboard/pull/184
- 対応issue: https://github.com/rictaworks/questboard/issues/181

## 非エンジニア向けユーザーテスト手順

**事前準備（開発担当者から受け取っておくもの）**
- 管理画面用のBasic認証情報（ユーザー名・パスワード）※環境変数 `ADMIN_BASIC_AUTH_USERNAME` / `ADMIN_BASIC_AUTH_PASSWORD` に設定されているものです
- 確認対象環境（開発環境またはステージング環境）のURL

**手順**

1. ブラウザで `https://<確認対象環境のURL>/admin/users` を開きます。
2. 認証を求めるポップアップが表示されたら、事前に受け取ったユーザー名とパスワードを入力してログインします。
3. ページが正常に表示され、「手動ログイン許可（例外ユーザー）管理」という見出しが見えることを確認します。
   - **これが表示されればOK**：エラー画面（500エラーなど）ではなく、上記の見出しを含む管理画面が表示されていればOKです。
4. 画面内のユーザー追加フォームで、項目をすべて空欄のまま「登録」ボタン（または追加のボタン）をクリックします。
5. ページが自動的に一覧画面へ戻り、画面上部または該当箇所に「入力内容に不備があります」といった趣旨のエラーメッセージ（赤字や黄色の帯など）が表示されることを確認します。
   - **これが表示されればOK**：エラー画面に飛ばず、一覧ページに戻ってメッセージが表示されていればOKです。
6. 一覧に表示されているユーザーの行にある「ログインを許可」（すでに許可済みの場合は「許可を解除」）ボタンをクリックします。
7. ページが自動的に一覧画面へ戻り、「手動ログイン許可状態を更新しました。」というメッセージが表示され、該当ユーザーの状態表示（「手動許可中」または「通常判定 (X API基準)」）が切り替わっていることを確認します。
   - **これが表示されればOK**：エラー画面に飛ばず、成功メッセージと状態表示の切り替わりが確認できればOKです。

以上3点（3の見出し表示、5のエラーメッセージ表示、7の成功メッセージと状態切り替え表示）が確認できれば、今回の修正が正しく反映されています。
