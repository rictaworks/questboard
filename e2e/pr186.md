# PR #186: 管理ユーザー画面のRack::MethodOverride欠落を修正（手動ログイン許可トグルが本番で機能しない不具合）

- PR: https://github.com/rictaworks/questboard/pull/186
- 対応issue: https://github.com/rictaworks/questboard/issues/181

## 非エンジニア向けユーザーテスト手順

1. 本番の管理画面 `/admin/users` にBasic認証（開発担当者からIDとパスワードを受け取ってください）でアクセスします
2. ユーザー一覧の中から、まだ「手動許可中」になっていない行（「通常判定 (X API基準)」と表示されている行）を探します
3. その行の「ログインを許可」ボタンをクリックします
4. **これが表示されればOK**: 画面上部に緑色の背景で「手動ログイン許可状態を更新しました。」というメッセージが表示され、該当ユーザーの「手動ログイン許可状態」列が「手動許可中」（青色バッジ）に変わっていること
5. 同じ行の「許可を解除」ボタンをクリックします
6. **これが表示されればOK**: 再び緑色の成功メッセージが表示され、「手動ログイン許可状態」列が「通常判定 (X API基準)」に戻っていること

以前は上記の操作をしても画面が変化せず、成功メッセージも表示されませんでした。
