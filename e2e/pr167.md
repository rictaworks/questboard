## 非エンジニア向けユーザーテスト手順

この変更は画面には表れず、Rails（バックエンド）のテストコードの整理のみを行うものです。以下の手順で「テストが問題なく通ること」を確認してください。

**事前に必要なもの**
- このリポジトリをパソコンにダウンロード（clone）済みであること
- Docker Desktop がインストールされ、起動していること
- 開発担当者から特別な認証情報を受け取る必要はありません

**手順**

1. パソコンで「ターミナル」（Macなら「ターミナル」、Windowsなら「コマンドプロンプト」や「WSL」）を開きます。
2. 以下のコマンドを1行ずつ入力し、Enterキーを押します。

   ```
   cd questboard
   docker compose up -d postgres
   ```

3. 少し待ってから（10秒ほど）、以下のコマンドを入力してEnterキーを押します。

   ```
   cd src/backend
   bundle exec rspec
   ```

4. コマンドの実行が終わるまで数分待ちます。

**合格ライン**

- 実行結果の最後の方に、赤い文字の "failures"（失敗）が **0件** と表示されていればOKです。
  - 例：`0 examples, 0 failures` のように「failures」の数字が0であればテスト成功です。
- もし数字が0でない場合や、赤いエラーメッセージが大量に表示された場合は、その画面をスクリーンショットで撮って開発担当者に共有してください。
