# PR #36: Googleログイン認証とreCAPTCHA付きセッション確立を追加

- PR: https://github.com/rictaworks/questboard/pull/36

## 非エンジニア向けユーザーテスト手順

### 準備（開発担当者から事前に受け取っておくもの）
このPRはGoogleログインを実装したものなので、確認には以下の値が必要です。開発担当者に発行してもらってください。
- Google Cloud ConsoleのOAuthクライアントID・シークレット・リダイレクトURI
- reCAPTCHA v3のサイトキー・シークレットキー

### 手順1: バックエンドを起動する
1. ターミナルを開き、次のフォルダに移動します。
   ```
   cd src/backend
   ```
2. 設定ファイルをコピーします。
   ```
   cp .env.example .env
   ```
3. `.env`ファイルを開き、`GOOGLE_OAUTH_CLIENT_ID`・`GOOGLE_OAUTH_CLIENT_SECRET`・`GOOGLE_OAUTH_REDIRECT_URI`・`RECAPTCHA_SECRET_KEY`に受け取った値を入力して保存します。
4. サーバーを起動します。
   ```
   bundle exec rails server
   ```
   「Listening on ...」と表示されれば成功です。

### 手順2: フロントエンドを起動する
1. 別のターミナルを開き、プロジェクトのルートフォルダに移動します。
2. `.env.local`というファイルを新規作成し、以下を書き込みます（値は受け取ったものに置き換えてください）。
   ```
   NEXT_PUBLIC_BACKEND_URL=http://localhost:3000
   NEXT_PUBLIC_GOOGLE_CLIENT_ID=（受け取ったクライアントID）
   NEXT_PUBLIC_GOOGLE_REDIRECT_URI=http://localhost:3001/auth/google/callback
   NEXT_PUBLIC_RECAPTCHA_SITE_KEY=（受け取ったサイトキー）
   ```
3. 以下のコマンドでフロントエンドを起動します（バックエンドと別ポートになるよう`-p 3001`を指定します）。
   ```
   npm install
   npm run dev -- -p 3001
   ```
4. ブラウザで `http://localhost:3001` を開きます。

### 手順3: ログイン前の画面を確認する
- 「ログイン」という見出しの下に「Googleで続ける」というボタンが表示されることを確認してください。

### 手順4: Googleでログインする
1. 「Googleで続ける」ボタンをクリックします。
2. Googleのログイン・同意画面に遷移することを確認してください。
3. 画面の指示に従ってGoogleアカウントでログインします。
4. 元の画面に自動的に戻り、「ログイン済みです」という表示と、あなたのGoogleアカウントの表示名が出ることを確認してください。

### 手順5: ログアウトを確認する
1. 「ログアウト」ボタンをクリックします。
2. 画面が「Googleで続ける」ボタンのある未ログイン状態に戻ることを確認してください。

### 手順6: 開発環境専用の自動ログイン表示を確認する（任意）
1. フロントエンドのターミナルを`Ctrl+C`で停止します。
2. `.env.local`に`NEXT_PUBLIC_ENV=development`の行を追加して保存します。
3. `npm run dev -- -p 3001`で再起動し、`http://localhost:3001`を開きます。
4. Googleログインをしていなくても「開発環境では認証済みとして扱われます」という表示が出ることを確認してください（本番ビルドではこの表示が出ないことは、担当エンジニアが別途自動テストで確認しています）。

### 合格ライン
- 手順3〜5がすべて説明通りに動作すること
- おかしな挙動があれば、どの手順で・どんな画面が表示されたかをスクリーンショット付きで開発担当者に共有してください
