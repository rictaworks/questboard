# PR #39: F7 権限判定関数（PermissionService）を追加

- PR: https://github.com/rictaworks/questboard/pull/39

## 非エンジニア向けユーザーテスト手順

このPRは画面のないバックエンドの権限判定ロジックの追加です（まだどの画面・APIからも呼び出されていません）。以下の手順で「ロジックが仕様通りに動くか」をコマンドの実行結果で確認できます。

### 手順1: バックエンドのフォルダに移動する
ターミナルを開き、以下をコピー&ペーストしてEnterキーを押してください。
```
cd src/backend
```

### 手順2: 自動テストを実行する
以下をコピー&ペーストしてEnterキーを押してください。
```
bundle exec rspec spec/services/permission_service_spec.rb --format documentation
```

### 合格ライン
実行結果の一番下に、次のような表示が出ればOKです。

```
7 examples, 0 failures
```

「0 failures（失敗ゼロ）」であることが重要です。表示された各項目（例：「covers the 4-role × 10-action × 2-lock-state matrix」など）は、権限マトリクスの全パターンが仕様通りに判定されていることを意味します。

もし`failures`の数字が0でない場合は、実行結果の全文をコピーして開発担当者に共有してください。
