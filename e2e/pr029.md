# PR #29: Questboardのデータベーススキーマと冪等マスタシードを追加

- PR: https://github.com/rictaworks/questboard/pull/29

## 非エンジニア向けのユーザーテスト手順

このPRには画面（UI）の変更はありません。データベースの土台部分（テーブル定義とマスタデータ）を作る変更のため、「コマンドを実行して正しい結果が表示されるか」を確認する形のテストになります。難しい専門知識は不要です、下記の通りコピー＆ペーストしていただければ確認できます。

### 準備
1. 開発環境（GitHub Codespaces など）で、このブランチ（`copilot/db-schema-migration-master-data-seed`）を開いてください
2. 画面下部にある黒い操作画面（ターミナル）をクリックして開いてください

### 手順1: バックエンドのフォルダに移動する
以下の文字列をコピーしてターミナルに貼り付け、Enterキーを押してください。
```
cd src/backend
```

### 手順2: 自動テストを実行する
以下の文字列をコピーしてターミナルに貼り付け、Enterキーを押してください。
```
bundle exec rspec spec/models/schema_and_seed_spec.rb --format documentation
```

### 確認すること（ここが合格ラインです）
実行結果の一番下のあたりに、次のような表示が出ればOKです。

```
Questboard database schema and seeds
  defines the required tables, columns, and constraints
  keeps Sqlite3JsonbCompat definitions in sync with actual database schema
  seeds the 72 master rows idempotently

3 examples, 0 failures
```

- 「3 examples, 0 failures」という部分が重要です。「0 failures（失敗ゼロ）」と表示されていれば正常に動いています
- もし「failures」の数字が0でない場合は、その実行結果の全文をコピーして担当エンジニアに共有してください

### 手順3（任意）: マスタデータが72件入っていることを実際の数字で確認する
もう少し具体的に確認したい場合は、以下を1行ずつ順番にコピーして実行してみてください（1行目でマスタデータを投入し、2行目で件数を数えます）。
```
RAILS_ENV=test bin/rails db:seed
```
```
RAILS_ENV=test bin/rails runner 'puts %w[roles object_types radial_menu_items effect_masters intensity_masters quests event_defs color_palettes].sum { |t| ActiveRecord::Base.connection.select_value("SELECT COUNT(*) FROM #{t}").to_i }'
```
最後に数字の「72」だけが表示されればOKです（役職4件＋オブジェクト種別6件＋ラジアルメニュー14件＋演出エフェクト12件＋演出強度3件＋クエスト8件＋イベント定義15件＋カラーパレット10件＝合計72件）。

> 補足: 手順3を実行すると、テスト用データベースに72件のデータが残ります。もう一度手順2（自動テスト）を実行したい場合は、先に以下を順番に実行してテスト用データベースを空の状態に戻してください。
> ```
> RAILS_ENV=test bin/rails db:drop
> ```
> ```
> RAILS_ENV=test bin/rails db:create
> ```
> ```
> RAILS_ENV=test bin/rails db:migrate
> ```

### このPRで「見えるもの」「見えないもの」
- 見えないもの: 画面上の見た目の変化はありません（データベースの内部構造だけの変更のため）
- 見えるもの: 上記テストコマンドの実行結果（合格「0 failures」／不合格）
