# PR #26: Next.js雛形・多言語対応基盤・デザイントークンを追加

- PR: https://github.com/rictaworks/questboard/pull/26

## 非エンジニア向け動作確認手順

エンジニアでなくても、以下の手順で画面を確認できます。ご自身のPCに Node.js（v20以上を推奨）がインストールされている前提です。

1. ターミナル（コマンドを打つ画面）を開き、このプロジェクトのフォルダに移動します。
2. 次のコマンドを順番に実行します。
   ```
   npm install
   npm run dev
   ```
3. ブラウザで `http://localhost:3000` を開きます。

4. **確認①：アドレスに言語の記号が付かないか**
   - アドレスバーが `http://localhost:3000/` のまま変わらないことを確認してください（以前は `/ja` が自動で付いていましたが、日本語のみになったため付かなくなりました）。

5. **確認②：日本語の文章が表示されているか**
   - 画面のいちばん上に「Questboard」という大きな見出しが表示されていることを確認してください。
   - その下に「ログイン」という見出しがあり、その中に「開発環境では認証済みとして扱われます」と表示されていることを確認してください（`npm run dev` で起動したときの正しい表示です。手順11の本番相当ビルドでは代わりに「Googleでログイン」が出ます）。
   - さらに下に「ボードを作成」という見出しと、「ボード名」の入力欄が表示されていることを確認してください。
   - 表示される文章がすべて日本語であることを確認してください。
   - ※このページは製品紹介ページではなくアプリの入口です。キャッチコピーや紹介文が出ないのが正しい状態です。

6. **確認③：デザイン（見た目）が崩れていないか**
   - 背景が濃い紫〜紺色のグラデーションになっていること
   - カード状の枠（角丸・薄い光る縁取り）が表示されていること
   - 見出しに装飾的なフォント（Cinzel）が使われていること
   を確認してください。

7. **確認④：アイコンが正しく表示されているか**
   - 「開発環境では認証済みとして扱われます」の文字の左側に、小さな盾のマークが表示されていることを確認してください（四角い枠や「豆腐」のような記号だけで絵が出ていない場合はNGです）。

8. **確認⑤：昔の言語つきURLが今も開けるか**
   - アドレスバーを `http://localhost:3000/ja` に変更し、Enterキーを押してください。
   - 自動的に `http://localhost:3000/` に移動し、確認②と同じ画面が表示されることを確認してください。
   - ※多言語をやめる前に配布された `/ja` 付きのリンクやブックマークが、今も使えることの確認です。

9. **確認⑥：昔の言語つき共有URLからも言語の記号が外れるか**
   - `http://localhost:3000/en/b/test123`、`/fr/b/test123`、`/zh/b/test123`、`/ru/b/test123`、`/es/b/test123`、`/ar/b/test123` に順にアクセスしてください。
   - いずれもアドレスが `http://localhost:3000/b/test123` に変わることを確認してください（言語の記号が外れます）。
   - ※この手順ではフロントエンドだけを起動しているため、移動した先のページには赤い文字でエラー（`NEXT_PUBLIC_BACKEND_URL is required` など）が出ます。**この確認で見るのはアドレスバーの変化だけ**で、ページの中身は見ません。ボードの中身の確認はサーバーを揃えたうえで別途行います。

10. **確認⑦：ポップアップ（警告ダイアログ）が出てこないか**
    - ページ内のボタンやリンクをひととおりクリックし、ブラウザ標準の警告ポップアップが一切出てこないことを確認してください。

11. **確認⑧：開発中専用の表示が本番用の画面に出ないか**
    - 開発サーバー（`npm run dev`）を一度 `Ctrl+C` で停止します。
    - 次のコマンドで本番相当のビルドを作成し、起動します。
      ```
      npm run build
      npm start
      ```
    - `http://localhost:3000/` を開き、「開発環境では認証済みとして扱われます」というバナーが**表示されていないこと**を確認してください（開発サーバーのときだけ表示され、本番ビルドでは表示されないのが正しい状態です）。

すべての項目で問題がなければ、動作確認は完了です。おかしな点があれば、該当する確認番号（例：確認③）とスクリーンショットを添えてご連絡ください。
