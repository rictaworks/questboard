## 非エンジニア向け動作確認手順

エンジニアでなくても、以下の手順で画面を確認できます。ご自身のPCに Node.js（v20以上を推奨）がインストールされている前提です。

1. ターミナル（コマンドを打つ画面）を開き、このプロジェクトのフォルダに移動します。
2. 次のコマンドを順番に実行します。
   ```
   npm install
   npm run dev
   ```
3. ブラウザで `http://localhost:3000` を開きます。

4. **確認①：自動で日本語ページに移動するか**
   - アドレスバーが自動的に `http://localhost:3000/ja` に変わることを確認してください。

5. **確認②：日本語の文章が表示されているか**
   - 「チームの意思決定をひとつの場所に集約する」という見出しが表示されていることを確認してください。
   - 「デザイントークンを見る」「ロケール構成を見る」という2つのボタンが表示されていることを確認してください。

6. **確認③：デザイン（見た目）が崩れていないか**
   - 背景が濃い紫〜紺色のグラデーションになっていること
   - カード状の枠（角丸・薄い光る縁取り）が表示されていること
   - 見出しに装飾的なフォント（Cinzel）が使われていること
   を確認してください。

7. **確認④：アイコンが正しく表示されているか**
   - 見出しの上にある「戦略ボード」という文字の左側に、小さな「言語」アイコン（吹き出しのようなマーク）が表示されていることを確認してください（四角い枠だけで絵が出ていない場合はNGです）。

8. **確認⑤：英語ページも表示できるか**
   - アドレスバーを `http://localhost:3000/en` に変更し、Enterキーを押してください。
   - 画面の文言がすべて英語に切り替わることを確認してください。

9. **確認⑥：他の言語ページがエラーにならないか**
   - `http://localhost:3000/fr`、`/zh`、`/ru`、`/es`、`/ar` にもアクセスし、エラー画面（Next.jsのエラー表示）にならないことを確認してください。
   - ※これらの言語はまだ翻訳作業中のため、文言が仮の英語表示（`[TODO] translate`）のままなのは問題ありません。

10. **確認⑦：ポップアップ（警告ダイアログ）が出てこないか**
    - ページ内のボタンやリンクをひととおりクリックし、ブラウザ標準の警告ポップアップが一切出てこないことを確認してください。

11. **確認⑧：開発中専用の表示が本番用の画面に出ないか**
    - 開発サーバー（`npm run dev`）を一度 `Ctrl+C` で停止します。
    - 次のコマンドで本番相当のビルドを作成し、起動します。
      ```
      npm run build
      npm start
      ```
    - `http://localhost:3000/ja` を開き、「開発環境では認証済みとして扱われます」というバナーが**表示されていないこと**を確認してください（開発サーバーのときだけ表示され、本番ビルドでは表示されないのが正しい状態です）。

すべての項目で問題がなければ、動作確認は完了です。おかしな点があれば、該当する確認番号（例：確認③）とスクリーンショットを添えてご連絡ください。
