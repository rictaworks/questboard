# PR #37: CI必須要件対応: GitHub Actionsワークフロー追加

- PR: https://github.com/rictaworks/questboard/pull/37

## 非エンジニア向けユーザーテスト手順

このPRはコードの動作画面には影響しません。以下の手順でCIが正しく動くことだけご確認ください。

1. このPRのページを開く
2. ページの下の方にある「Checks」というタブ、または「All checks have passed」といった表示を確認する
3. 6つのチェック（ESLint / build & test / go test / RSpec / RuboCop / Brakeman）が緑色のチェックマーク（✅）になっていればOKです
4. もし赤い✕マークがあれば、そのチェック名をクリックすると失敗した詳細ログが見られます。その場合はスクリーンショットを撮って開発担当に共有してください
