# PR #42: オブジェクト(付箋/図形/テキスト/接続線/画像/フレーム)のCRUD APIを追加

- PR: https://github.com/rictaworks/questboard/pull/42

## 非エンジニア向けユーザーテスト手順

このPRは画面のないバックエンドAPIの追加です（ボード上でオブジェクトを実際にドラッグ操作できる画面は、別のIssueで今後追加されます）。以下の手順で「APIが仕様通りに動くか」をコマンドの実行結果で確認できます。

### 手順1: バックエンドのフォルダに移動する
ターミナルを開き、以下をコピー&ペーストしてEnterキーを押してください。
```
cd src/backend
```

### 手順2: 自動テストを実行する
以下をコピー&ペーストしてEnterキーを押してください。
```
bundle exec rspec spec/requests/objects_spec.rb --format documentation
```

### 合格ライン
実行結果の一番下に、次のような表示が出ればOKです。

```
6 examples, 0 failures
```

「0 failures（失敗ゼロ）」であることが重要です。表示された各項目（例：「creates every supported object type」「moves, resizes, rotates, and tombstones objects while enforcing permissions」など）は、それぞれオブジェクトの作成・移動・権限チェック・削除などが仕様通りに動くことを意味します。

もし`failures`の数字が0でない場合は、実行結果の全文をコピーして開発担当者に共有してください。
