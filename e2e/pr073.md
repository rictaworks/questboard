# PR #73: AnalyticsTrackerがグローバル関数を不正なレシーバで呼ぶ問題を修正 (#72)

- PR: https://github.com/rictaworks/questboard/pull/73

## ユーザーテスト手順

前提：本番 https://questboard.rictaworks.jp に Google ログイン済みであること。

1. DevTools > Application > Local Storage で `questboard.analytics.*` のキーが残っていれば**すべて削除**する
2. `https://questboard.rictaworks.jp/ja/b/<share_token>` を開く → ボードが正常に表示されることを確認
3. HUD の「演出強度」を「控えめ」に変更する
4. DevTools > Application > Local Storage に `questboard.analytics.<userId>.<boardId>` が作られ、`intensity_changed` を含む配列が入っていることを確認
5. ページを再読み込みする
6. **→ タブがクラッシュせず、ボードが正常に表示されることを確認**（修正前はここで "This page couldn't load" になっていた）
7. DevTools > Console に `Illegal invocation` が出ていないことを確認
8. キャンバスをドラッグ（`camera_panned`）、ホイールでズーム（`camera_zoomed`）、ラジアルメニューを開く（`radial_opened`）をそれぞれ行い、都度リロードしてクラッシュしないことを確認
9. 10 秒待つと DevTools > Network に `POST /kpi_events` が飛び、localStorage の当該キーが `[]` になることを確認
10. 既に壊れた状態のユーザーの復旧確認：手順 1 を行わず（＝古いバッファが残ったまま）ボードを開いてもクラッシュしないことを確認
