# PR #41: ボード作成・共有URL招待・オーナー限定ロール変更を追加

- PR: https://github.com/rictaworks/questboard/pull/41

## 非エンジニア向けユーザーテスト手順

このPRには実際に操作できる画面があります。可能であれば、Googleアカウントを2つ（オーナー役・参加者役）用意してご確認ください。

### 準備
1. バックエンド（`src/backend`）とフロントエンドをそれぞれ起動してください（起動手順はPR #36の本文、またはREADMEを参照）
2. ブラウザでトップページを開き、1つ目のGoogleアカウントでログインします

### 手順1: ボードを作成する
1. ログイン後の画面で「ボード作成」欄にボード名（例：「テストボード」）を入力し、作成ボタンを押します
2. 画面に「共有用URL」が表示されることを確認してください

### 合格ライン（手順1）
- URLのような文字列（`/b/`で始まる）が表示されればOKです

### 手順2: 招待URLから参加する
1. 手順1で表示された共有URLをコピーします
2. 別のブラウザ（またはシークレット/プライベートウィンドウ）を開き、そのURLに直接アクセスします
3. 2つ目のGoogleアカウントでログインします
4. 参加時のロール（閲覧のみ／コメント可／編集可）を選び、参加ボタンを押します

### 合格ライン（手順2）
- 「参加しました」という趣旨の成功メッセージと、選んだロール名が表示されればOKです

### 手順3（任意・エンジニア確認向け）: owner以外がロールを変更できないことの確認
このロール変更機能はまだ専用の画面がなく、ターミナルからのコマンドでの確認になります。開発担当者と一緒に、以下の内容を確認してください。

- 参加者（owner以外）が他人のロールを変更しようとすると、拒否される（403エラー）こと
- 唯一のownerが自分自身のロールを引き下げようとすると、拒否される（422エラー、「Cannot remove the last owner」というメッセージ）こと

### すべてがOKなら
- 手順1・手順2の画面表示が説明通りであれば、動作確認は完了です
- おかしな点があれば、どの手順で・どんな画面が表示されたかをスクリーンショット付きで開発担当者に共有してください
