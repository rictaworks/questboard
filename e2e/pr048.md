# PR #48: F3 ゲームカメラ制御関数（CameraController）を追加

- PR: https://github.com/rictaworks/questboard/pull/48

## 非エンジニア向けユーザーテスト手順

このPRは画面のないロジック層の追加です（実際にキャンバス上でパン/ズーム操作できる画面への組み込みは、別のPRで今後行われます）。以下の手順で「仕様通りに動くか」をコマンドの実行結果で確認できます。

### 手順1: ターミナルを開く
プロジェクトのルートフォルダ（`questboard`）でターミナルを開いてください。

### 手順2: 依存パッケージが入っていることを確認する
初めて動かす場合は、以下をコピー&ペーストしてEnterキーを押してください（既にインストール済みの場合は不要です）。
```
npm install
```

### 手順3: 自動テストを実行する
以下をコピー&ペーストしてEnterキーを押してください。
```
node --test test/camera-controller.test.mjs
```

### 合格ライン
実行結果の最後の方に、次のような表示が出ればOKです。

```
ℹ tests 4
ℹ pass 4
ℹ fail 0
```

「fail 0（失敗ゼロ）」であることが重要です。表示された各項目（例：「pan to inertia maintains directional continuity across zoom levels」「resolveCameraRange locks camera position to content center when viewport exceeds expanded bounds」など）は、パンから慣性へ移行しても進行方向が変わらないこと、画面が小さいコンテンツを大きくズームアウトしてもカメラが変な位置に飛ばないことなど、カメラ操作の仕様が守られていることを意味します。

もし`fail`の数字が0でない場合は、実行結果の全文をコピーして開発担当者に共有してください。
