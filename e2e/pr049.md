# PR #49: F2 ラジアルメニュー構成関数（RadialMenuBuilder）を追加

- PR: https://github.com/rictaworks/questboard/pull/49

## 非エンジニア向けユーザーテスト手順

このPRは画面のないロジック層の追加です（実際にラジアルメニューが表示される画面への組み込みは、別のPRで今後行われます）。以下の手順で「仕様通りに動くか」をコマンドの実行結果で確認できます。

### 手順1: バックエンドのフォルダに移動する
ターミナルを開き、以下をコピー&ペーストしてEnterキーを押してください。
```
cd src/backend
```

### 手順2: 自動テストを実行する
以下をコピー&ペーストしてEnterキーを押してください。
```
bundle exec rspec spec/services/radial_menu_builder_spec.rb --format documentation
```

### 合格ライン
実行結果の一番下に、次のような表示が出ればOKです。

```
6 examples, 0 failures
```

「0 failures（失敗ゼロ）」であることが重要です。表示された各項目（例：「returns empty menu and visible false for unknown target kinds」「omits comment action from blank canvas menu」など）は、想定外の対象や実行できない操作がメニューに表示されないなど、安全側に倒れた仕様が守られていることを意味します。

もし`failures`の数字が0でない場合は、実行結果の全文をコピーして開発担当者に共有してください。
