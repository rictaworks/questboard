# PR #150: ボードキャンバスのレイアウトにPlaywrightでの回帰テストを追加

- 対応issue: https://github.com/rictaworks/questboard/issues/110

## 非エンジニア向けユーザーテスト手順

このPRはテスト用の仕組み（自動チェック）とその確認用ページの追加が中心です。以下の手順で、実際の画面を見て確認できます。**事前に必要な認証情報やAPIキーはありません**（ログイン不要でアクセスできる確認用ページです）。

### A. ブラウザで見た目を確認する

1. 開発担当者にこのPRのブランチ名（`copilot/verify-board-layout-with-playwright`）を伝えてもらい、パソコンでこのリポジトリのフォルダを開いてもらう（または開発担当者の画面を一緒に見る）。
2. ターミナル（黒い画面）に、次のコマンドを1行ずつコピー&ペーストして実行してもらう。
   ```
   git checkout copilot/verify-board-layout-with-playwright
   npm install
   npm run dev
   ```
3. 「Ready」や「started server」といった文字が出たら、ブラウザ（Chromeなど）を開き、アドレスバーに次のURLを入力する。
   ```
   http://localhost:3000/board-layout-fixture
   ```
4. **合格ライン1（パソコン表示）**：ブラウザのウィンドウを普通の大きさ（横幅を画面いっぱいくらい）に広げた状態で、画面右端に縦の長いスクロールバーが出ていなければOKです。付箋やコメントの一覧など、パネルの中だけで小さくスクロールできればOKです。
5. ブラウザの右上にある「×」で閉じずに、ウィンドウの端をドラッグして画面を細く狭める（スマートフォンの画面くらいの幅、目安として半分以下）。
6. **合格ライン2（スマホ表示）**：画面全体を上下にスクロールできる状態になっていればOKです。ボードの表示エリア（枠で囲まれた部分）が極端に潰れて見えなくなっていなければOKです。
7. 画面上部に出ている「参加が完了しました」というお知らせバナーの「閉じる」ボタン（×マーク）を押す。
8. **合格ライン3**：バナーを閉じた後も、レイアウトが崩れたり文字が重なったりしていなければOKです。

### B. 自動チェック（CI）の結果を確認する

1. GitHub上でこのPR（#150）のページを開く。
2. ページ内の「Checks」（チェック）タブ、または「All checks have passed」といった表示部分を確認する。
3. **合格ライン**：一覧の項目がすべて緑色のチェックマーク（✓）になっていればOKです。特に「playwright」という名前を含む項目が緑になっていることを確認してください。赤い×印がある場合は、まだ確認完了とはせず開発担当者に共有してください。
