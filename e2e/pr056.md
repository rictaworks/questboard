# PR #56: フロントエンドのリアルタイム同期・presenceカーソル・削除復元UXを統合

- PR: https://github.com/rictaworks/questboard/pull/56

## 非エンジニア向けユーザーテスト手順

### 事前に準備するもの（開発担当者から受け取ってください）

- テスト対象の開発サーバーのURL（例: `https://xxxxx.example.com` のような形）
- テスト用の「ボード共有リンク」（`/b/xxxxxxxx` のような形のURL）。まだ無ければ開発担当者にボードを1つ作ってもらい、共有リンクを発行してもらってください。
- 開発環境ではGoogleログインなしでそのまま使える設定になっているはずですが、もしログイン画面が出て進めない場合は開発担当者に確認してください。

### 手順1: 複数人で同時に編集できるか確認する（リアルタイム同期）

1. パソコンのブラウザ（Google Chrome推奨）で、上記の「ボード共有リンク」を開きます。
2. 同じブラウザでもう一つ新しいタブを開き（キーボードの `Ctrl+T`、Macなら `Cmd+T`）、同じ「ボード共有リンク」をもう一度開きます。これで画面が2つ、同じボードを表示している状態になります。
3. 片方のタブ（タブA）で、ボード上の付箋やカードなどを1つドラッグして位置を動かしてみます。
4. もう片方のタブ（タブB）を見て、数秒以内に同じ位置の変化が反映されることを確認します。

**合格ライン**: タブAで動かした操作が、タブBの画面にも自動的に（ページの再読み込みをしなくても）反映されれば成功です。

### 手順2: 他の人のカーソル（presence）が見えるか確認する

1. 手順1と同じように、同じボードを2つのタブ（タブA・タブB）で開いた状態にします。
2. タブAの画面上でマウスカーソルをゆっくり動かします。
3. タブBの画面を見て、タブA側の動きに合わせて「誰かのカーソル」がボード上に表示され、動くことを確認します。カーソルのそばに名前（表示名）がラベルとして出ていることも確認します。

**合格ライン**: タブBの画面上に、タブA側の操作に連動して動くカーソルと名前ラベルが表示されれば成功です。以前は名前が出ず、決まった位置に固定のダミーカーソルが出るだけでしたが、今回からは実際に動いている相手の名前と位置が表示されます。

### 手順3: オフラインにしてから再接続しても操作が反映されるか確認する

1. ボードの共有リンクをブラウザで開きます。
2. ブラウザの開発者ツールを使わずに確認する場合は、パソコンのWi-Fiを一時的に切る、または機内モードにしてインターネット接続を切断します。
3. 接続が切れた状態のまま、ボード上の付箋やカードを1つ動かしてみます（この時点では他の人には反映されません）。
4. Wi-Fiや接続を元に戻し、インターネットに再接続します。
5. 数秒待って、画面上部などに表示される接続状態の表示（オフライン→再接続中→オンラインなど）が「オンライン」に戻ることを確認します。
6. 手順3で行った操作（付箋やカードの移動）が、そのままボードに反映され続けていることを確認します（消えていないこと）。

**合格ライン**: 接続を切っている間に行った操作が消えずに残り、再接続後も正しくボードに反映されていれば成功です。

### 手順4: 削除したものを復元できるか確認する（F7キー操作）

1. ボードの共有リンクを開きます。
2. ボード上のカードや付箋を1つ選んで削除します（削除ボタンや右クリックメニューなど、通常の削除操作を行ってください）。
3. 削除した直後に、画面下部などに出る通知（トースト）を確認します。「元に戻す」「復元」などの操作案内が出る場合があります。
4. キーボードの `F7` キーを押しながら、その通知に表示されている「復元」ボタンをクリックします。
5. 削除したはずのカードや付箋が、ボード上に元どおり表示されることを確認します。

**合格ライン**: `F7` キーを押しながらでないと復元ボタンが反応せず、`F7` キーを押しながらクリックすると削除したものが元に戻れば成功です。また、ブラウザ標準のポップアップ（「OK」「キャンセル」などが出る灰色のダイアログ）が一切表示されないことも確認してください（表示された場合は不具合です）。

### うまくいかない場合

- 上記のいずれかで「反映されない」「エラーが表示される」「画面が固まる」といった問題が発生した場合は、どの手順の何番でどうなったか（できればスクリーンショット付きで）を開発担当者に報告してください。
