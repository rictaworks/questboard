# PR #152: サイドバーの入れ子スクロール発生をミニマップの可変高さ化で軽減

- PR: https://github.com/rictaworks/questboard/pull/152
- 対応issue: https://github.com/rictaworks/questboard/issues/111

## 非エンジニア向けユーザーテスト手順

事前に用意していただくもの: 特にありません（開発環境では自動的にログイン済み扱いになるため、アカウントやパスワードは不要です）。

1. ターミナル（黒い画面のアプリ）を開き、リポジトリのフォルダで次のコマンドを実行してください。
   ```
   npm run dev
   ```
2. 「Local: http://localhost:3000」のような表示が出たら、ブラウザ（Google Chromeなど）を開き、アドレス欄に次のURLを入力してアクセスしてください。
   ```
   http://localhost:3000/board-layout-fixture
   ```
3. 画面の左側に大きな作業スペース（付箋やコメントが置かれたボード）、右側に「クエスト一覧」「詳細」「小さな全体地図（ミニマップ）」が縦に並んだサイドバーが表示されればOKです。
4. ブラウザウィンドウの右下の角にマウスを合わせてドラッグし、ウィンドウの「縦の高さ」を、ノートパソコンで開いたときくらいの高さ（目安として画面の半分〜3分の2程度）まで小さくしてください。
   - うまく縮められない場合は、キーボードの `F12` キーを押して画面右または下に出てくるパネルの上部にある「端末のアイコン（デバイスツールバー切り替え）」をクリックし、サイズ欄に幅 `1366`・高さ `640` と入力しても同じ状態を再現できます。
5. ウィンドウを縮めた状態のまま、右側のサイドバー（クエスト一覧・詳細・ミニマップ）を上から下まで見てください。
6. **合格ライン**: サイドバーの中に「二重のスクロールバー」が出ておらず、内容が窮屈に見切れることもなく、ミニマップ（右下の小さい盤面）が横幅に合わせて適切な高さに縮んで表示されていれば合格です。
7. 参考確認として、ウィンドウをさらに縦長のスマートフォンサイズ（幅390×高さ844くらい）まで小さくした場合は、ページ全体がスクロールできる状態になることも確認してください。こちらは正常な挙動です。
8. 逆に、ウィンドウを元の大きさ（縦の高さがある程度広い状態）に戻したときも、ミニマップが極端に潰れておらず、他のパネルと同程度の高さで表示されていることを確認してください。
