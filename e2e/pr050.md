# PR #50: F4 フィードバック演出決定関数（FeedbackDirector）を追加

- PR: https://github.com/rictaworks/questboard/pull/50

## 非エンジニア向けユーザーテスト手順

このPRは画面のないロジック層の追加です（実際に演出がキャンバス上で再生される画面への組み込みは、別のPRで今後行われます）。以下の手順で「仕様通りに動くか」をコマンドの実行結果で確認できます。

### 手順1: ターミナルを開く
プロジェクトのルートフォルダ（`questboard`）でターミナルを開いてください。

### 手順2: 依存パッケージが入っていることを確認する
初めて動かす場合は、以下をコピー&ペーストしてEnterキーを押してください（既にインストール済みの場合は不要です）。
```
npm install
```

### 手順3: 自動テストを実行する
以下をコピー&ペーストしてEnterキーを押してください。
```
node --test test/feedback-director.test.mjs
```

### 合格ライン
実行結果の最後の方に、次のような表示が出ればOKです。

```
ℹ tests 5
ℹ pass 5
ℹ fail 0
```

「fail 0（失敗ゼロ）」であることが重要です。表示された各項目（例：「FeedbackDirector covers the 12 × 3 × 2 matrix and keeps feedback non-blocking」「effect durations and event-to-effect routing stay in sync with the seeded master data」など）は、演出が常に400ms以内・非モーダル・入力を妨げないこと、reduced-motion設定時に自動的に控えめな表示へ切り替わることなど、仕様が守られていることを意味します。

もし`fail`の数字が0でない場合は、実行結果の全文をコピーして開発担当者に共有してください。
