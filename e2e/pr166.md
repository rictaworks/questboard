# PR #166: seedとマイグレーションでユニークインデックス名を共有する

- PR: https://github.com/rictaworks/questboard/pull/166
- 対応issue: https://github.com/rictaworks/questboard/issues/30

## 非エンジニア向けユーザーテスト手順

この変更は画面のない、データベースの内部処理（データの初期投入と整合性チェック）に関するものです。画面を操作する手順はありません。以下のコマンドを実行し、結果を確認してください。

**事前に必要なもの**
- 開発担当者からリポジトリの初期セットアップ（Docker、Ruby 3.4.10、依存パッケージのインストール）が完了した状態のPCを用意してもらってください。追加のパスワードやAPIキーは不要です。

**手順**

1. ターミナル（黒い画面のアプリ）を開きます。
2. 次のコマンドを1行ずつコピーして貼り付け、Enterキーを押します。プロジェクトのフォルダに移動します。
   ```
   cd questboard
   ```
3. データベースを起動します。
   ```
   docker compose up -d postgres
   ```
4. 少し待ってから（10秒程度）、確認用のテストを実行します。
   ```
   cd src/backend && bundle exec rspec spec/models/schema_and_seed_spec.rb
   ```
5. 画面に次のような表示が出れば成功です（数字がすべて同じであることを確認してください）。
   ```
   3 examples, 0 failures
   ```
   - 「0 failures」と表示されていればOKです。これは「用意されたテストが3つとも成功した」という意味です。
   - もし数字が異なる、または赤字で「failures」に0以外の数字が出た場合は、開発担当者に画面のスクリーンショットを添えて連絡してください。

以上で確認は完了です。
