# PR #149: `:has()` 非対応環境でも board stage が潰れないように最小高さを既定化

- PR: https://github.com/rictaworks/questboard/pull/149
- 対応issue: https://github.com/rictaworks/questboard/issues/109

## 非エンジニア向けユーザーテスト手順

このPRはCSSの見た目の調整（レイアウト崩れの予防）です。通常お使いのパソコン・スマートフォンのブラウザ（Chrome, Edge, Safari最新版など）では見た目は変わりません。以下の手順で「今まで通り正常に表示されること」を確認してください。

1. ボード画面（トップページ、ボードが表示される画面）をブラウザで開く
2. カード（クエスト）が並んでいるキャンバス領域が画面に表示されていることを確認する
   - 合格ライン: キャンバスの領域が真っ白や真っ黒に潰れておらず、カードやレーンがこれまで通り見える
3. ブラウザの画面幅を狭くする（ウィンドウ端をドラッグして縮める、またはスマートフォンで表示する）
   - 合格ライン: 画面が狭くなってもキャンバス領域が潰れて見えなくなったりしない
4. 上記2点が確認できればOKです。見た目に変化がなければ正常に修正できています。

※本修正は「特殊な古いブラウザ（Safari 15.3以前、Firefox 120以前など）でキャンバスが真っ白になる不具合」を防ぐためのものです。開発担当が用意した環境でその古いブラウザの動作確認まで実施済みのため、非エンジニアの方は上記の通常ブラウザでの見た目確認のみで問題ありません。事前に受け取る必要がある認証情報やAPIキーはありません。
