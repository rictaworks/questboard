# PR #140: 製品版 F1: ペンをポインタ同等に扱い、描画分岐を除去

- PR: https://github.com/rictaworks/questboard/pull/140
- 対応issue: https://github.com/rictaworks/questboard/issues/136

## 非エンジニア向けユーザーテスト手順

このPRは画面のないロジック層（入力の解釈ルール）の変更です。「ペンで触れたときにフリーハンドの線を描く」機能を廃止し、ペンもマウスと同じように「選択・移動」として扱うようにする変更です。実際の画面での見た目の変化はまだ無く、以下の手順で「仕様通りに動くか」をコマンドの実行結果で確認できます。

事前に受け取っておくもの: 特にありません（APIキーやログイン情報は不要です）。

### 手順1: ターミナルを開く
プロジェクトのルートフォルダ（`questboard`）でターミナルを開いてください。

### 手順2: 依存パッケージが入っていることを確認する
初めて動かす場合は、以下をコピー&ペーストしてEnterキーを押してください（既にインストール済みの場合は不要です）。
```
npm install
```

### 手順3: 自動テストを実行する
以下をコピー&ペーストしてEnterキーを押してください。
```
node --test test/input-intent-resolver.test.mjs
```

### 合格ライン
実行結果の最後の方に、次のような表示が出ればOKです。

```
ℹ tests 28
ℹ pass 28
ℹ fail 0
```

「fail 0（失敗ゼロ）」であることが重要です。特に次の項目が緑色のチェック（✔）で表示されていれば、「ペンで線を描く」機能が無くなり、ペンもマウスと同じ選択・移動の挙動になったことを意味します。

- `resolveCanvasIntent returns the expected intent for key F1 scenarios`

もし`fail`の数字が0でない場合は、実行結果の全文をコピーして開発担当者に共有してください。
