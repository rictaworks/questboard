# PR #68: UC11の演出強度設定をサーバーに永続化する

- PR: https://github.com/rictaworks/questboard/pull/68

## 非エンジニア向けユーザーテスト手順

このテストを行うには、事前に開発担当者から以下を受け取ってください。
- テスト用アカウントのログイン情報（Xログイン用のテストアカウント、または開発環境用の自動ログインURL）
- テスト対象の環境のURL（開発環境またはステージング環境のフロントエンドURL）

### 手順

1. 教えてもらったURLをブラウザ（Chrome推奨）で開きます。
2. ログインします（テストアカウントで、または案内された自動ログインURLにアクセスします）。
3. クエストボード画面を開きます。
4. 画面上部（HUD）にある「演出強度」のドロップダウン（選択欄）を見つけます。初期状態は「フル」になっているはずです。
5. ドロップダウンをクリックし、「控えめ」を選択します。
   - 合格ライン：選択した瞬間に、画面上の演出（エフェクトなど）が控えめな見た目に変わり、ドロップダウンの表示が「控えめ」になっていればOKです。
6. ブラウザの再読み込みボタン（またはF5キー）を押して、ページを再読み込みします。
   - 合格ライン：再読み込み後もドロップダウンが「控えめ」のまま表示されていればOKです（「フル」に戻ってしまう場合はNGです）。
7. 同じ手順で、今度は「オフ」を選択し、再読み込みします。
   - 合格ライン：再読み込み後も「オフ」のまま表示されていればOKです。
8. 最後に「フル」に戻して、再読み込みします。
   - 合格ライン：再読み込み後も「フル」のまま表示されていればOKです。
9. （管理者アカウントをお持ちの場合のみ）管理者向けKPIダッシュボードを開き、「演出強度の設定分布」という項目を探します。
   - 合格ライン：数値やグラフが表示され、エラーメッセージが出ていなければOKです。

上記すべてで「合格ライン」を満たしていれば、このPRの動作確認は完了です。何か表示がおかしい場合や、選択した内容が再読み込みでリセットされてしまう場合は、担当者に画面のスクリーンショットとともにご連絡ください。
