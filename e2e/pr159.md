# PR #159: Xフォロー対象ハンドルの正規化によるプロフィールリンク修正

- PR: https://github.com/rictaworks/questboard/pull/159
- 対応issue: https://github.com/rictaworks/questboard/issues/154

## 非エンジニア向けユーザーテスト手順

この修正は「プランが利用できません」画面の「〇〇のプロフィールを開く」ボタンのリンク先を直す変更です。ただし、今回の不具合は環境変数に「目に見えない不正な文字」が入っていた場合にだけ再現するため、一番確実な確認方法は「自動テストの実行結果を確認する」方法です。以下の手順で確認してください。

### 事前に必要なもの

- このプロジェクトのソースコードが入った端末（開発担当者にリポジトリのセットアップを依頼してください）
- 特別なパスワードやAPIキーは不要です

### 手順

1. 開発担当者に依頼して、この端末でリポジトリを開いてもらう、またはターミナル（黒い画面のコマンド入力ツール）を開いてもらう。
2. ターミナルに以下のコマンドを1行ずつコピー＆ペーストして、Enterキーを押す。

   ```
   git fetch origin pull/159/head:pr159
   git checkout pr159
   ```

3. 続けて、以下のコマンドを実行する。

   ```
   node --test test/x-auth.test.mjs
   ```

4. 画面に以下のような行が表示されればOKです。

   ```
   ✔ buildXAuthorizationUrl generates a valid X OAuth2 authorization URL
   ✔ readFollowTargetHandle trims BOM and surrounding whitespace
   ✔ readFollowTargetHandle rejects values that become empty after normalization
   ...
   ℹ pass 3
   ℹ fail 0
   ```

   - 「pass」の数だけ緑のチェック（✔）が付いていて、「fail 0」となっていれば合格です。
   - もし「fail」が1つでもあれば、その内容をスクリーンショットで開発担当者に共有してください。

5. 確認が終わったら、以下のコマンドで元の状態に戻す。

   ```
   git checkout main
   ```

### 画面でも確認したい場合（任意）

開発担当者がテスト用の環境変数を設定してくれた場合は、以下も確認できます。

1. アプリのトップページ（開発担当者から共有されたURL）を開く。
2. まだ `@rictaworks` をフォローしていないXアカウントでログインする。
3. 「このプランでは利用できません」という見出しの画面が表示される。
4. 「〇〇のプロフィールを開く」というボタンをクリックする。
5. 新しいタブでXの正しいプロフィールページ（404エラーではないページ）が開けばOKです。
