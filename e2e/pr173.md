# PR #173: 削除の復元操作をF7同時押しから2段階確認ボタン方式に変更（アクセシビリティ改善）

- PR: https://github.com/rictaworks/questboard/pull/173
- 対応issue: https://github.com/rictaworks/questboard/issues/57

## 非エンジニア向けユーザーテスト手順

### 事前準備
- 開発担当者から、テスト用のボードのURL（例：`https://<開発環境のURL>/b/xxxxxxxx`）と、ログインが必要な場合はテスト用アカウント情報を受け取ってください。

### 手順

1. 受け取ったURLをブラウザで開いてください。
2. ボード画面が表示されたら、付箋（四角いカード）を1つクリックして選択してください。
3. 画面上部のツールバーにある「削除」ボタンをクリックしてください。
   - **合格ライン**: 付箋が画面から消え、画面下部に削除を知らせる通知（トースト）が表示され、その中に「復元」ボタンが見えること。
4. 表示された「復元」ボタンを1回クリックしてください。
   - **合格ライン**: ボタンの表示が「復元を確定」に変わり、隣に新しく「キャンセル」ボタンが表示されること。（この時点ではまだ付箋は元に戻りません）
5. 「復元を確定」ボタンをクリックしてください。
   - **合格ライン**: 消えていた付箋が画面上に再び表示されること。
6. もう一度手順2〜4を行い、今度は「復元を確定」ではなく「キャンセル」ボタンをクリックしてください。
   - **合格ライン**: ボタンの表示が元の「復元」ボタンに戻ること。付箋はまだ削除されたままであること。

### キーボードのみでの確認（可能であれば）

7. マウスを使わず、`Tab`キーで「復元」ボタンにカーソル（青い枠）が当たるまで移動し、`Enter`キーを押してください。
   - **合格ライン**: 手順4と同じく「復元を確定」「キャンセル」ボタンが表示され、かつ引き続き「復元を確定」ボタンにカーソル（青い枠）が当たっていること。そのままマウスを使わず`Enter`キーだけで確定・キャンセルの操作ができること。

上記すべてが期待どおりに表示・動作すれば、このPRの変更内容に問題ありません。
